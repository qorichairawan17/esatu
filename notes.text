   - Kolom DataTable mencakup ID Daftar, Tanggal Daftar, dan Tahapan.

Version 2.1.0 (16 April 2026)
================================================================================

[FITUR BARU]
------------
1. Dashboard Monitoring & Evaluasi:
   - Halaman dashboard baru untuk monitoring dan evaluasi kinerja aplikasi.
   - Grafik statistik pendaftaran surat kuasa (harian, bulanan, kuartalan,
     semester, tahunan) dengan filter rentang tanggal.
   - Kartu ringkasan: total pendaftaran, disetujui, ditolak, dan dalam proses.
   - Tabel peringkat Top 10 Advokat berdasarkan jumlah pendaftaran.
   - Tabel kinerja Panitera (jumlah approval) dan Verifikator.
   - Grafik distribusi status surat kuasa (pie/donut chart).
   - Data rata-rata pendaftaran bulanan dan persentase pertumbuhan tahunan.
   - Daftar testimoni terbaru dari pengguna.
   - API endpoint terpisah (/chart-data) untuk data grafik secara dinamis.

2. Implementasi Repository Pattern:
   - Penambahan MonitoringRepository sebagai abstraksi akses data.
   - Arsitektur Controller → Service → Repository untuk fitur Monitoring.

3. Toggle Visibility Password di Halaman Login:
   - Tombol ikon mata untuk menampilkan/menyembunyikan password pada form login.

4. Modal Verifikasi Surat Kuasa:
   - Komponen modal baru (modal-verifikasi) untuk proses verifikasi surat kuasa.

[KEAMANAN]
----------
1. Perbaikan Privilege Escalation pada Manajemen Administrator:
   - Non-Superadmin tidak dapat melihat akun Superadmin di daftar pengguna.
   - Non-Superadmin tidak dapat mengedit atau menghapus akun Superadmin.
   - Non-Superadmin tidak dapat memberikan role Superadmin kepada pengguna lain.
   - Validasi role pada AdministratorRequest dibatasi hanya untuk role yang valid
     (Superadmin dan Administrator) menggunakan Enum.

2. Perbaikan XSS pada Form Pendaftaran Surat Kuasa:
   - Penggunaan Js::from() untuk output data JSON yang aman di Blade template.

3. Validasi Email Unik pada Registrasi:
   - Penambahan validasi keunikan email pada AuthRegisterRequest.

[PERBAIKAN UI/UX]

   - Desain ulang tampilan dashboard administrator dengan style premium.
   - Penambahan file CSS khusus (premium-dashboard.css).

2. Redesign Dashboard Pengguna (home-pengguna):
   - Desain ulang tampilan dashboard pengguna dengan layout yang lebih modern.

3. Redesign Halaman Detail Surat Kuasa:
   - Overhaul tampilan halaman detail surat kuasa dengan layout baru.
   - Penambahan file CSS khusus (detail-surat-kuasa.css).

4. Redesign Halaman Pembayaran Surat Kuasa:
   - Perbaikan tampilan halaman pembayaran dengan layout yang lebih rapi.
   - Penambahan file CSS khusus (pembayaran-surat-kuasa.css).

5. Redesign Halaman Pejabat Struktural:
   - Perbaikan tampilan dan layout halaman pengaturan pejabat struktural.

6. Perbaikan Halaman Detail Advokat/Non-Advokat:
   - Peningkatan tampilan dan layout halaman detail pengguna advokat.

7. Perbaikan Tampilan Halaman Autentikasi:
   - Tombol login dan Google Sign-In menggunakan rounded-pill style.
   - Perbaikan layout pada halaman forgot-password dan signup.
